# Changelog

## 0.1.0

### Added

- Text casing and transformation utilities: `capitalize_words`, `snake_case`,
  and `reverse`.
- Text counting utilities: `character_count` and `word_count`.
- `word_frequency` for normalized word counts with common stop-word filtering.
- Automated pytest coverage for the public text utilities.
- Code-quality checks using Black, Ruff, and pre-commit.
- GitHub Actions workflows to run pytest and pre-commit checks on pull requests.
